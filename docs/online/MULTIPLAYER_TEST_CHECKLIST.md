# ECLIPSE ONLINE — รายการทดสอบหลายเครื่อง (N10)

ใช้ทดสอบเองด้วยมือ 2-4 หน้าต่าง/เครื่อง หลังแก้ระบบออนไลน์ทุกครั้ง ทำทีละข้อ ติ๊ก ✅ / ❌ แล้วจดอาการถ้าไม่ผ่าน

## เตรียมตัว
1. เปิดเซิร์ฟเวอร์: `node server.js` — หน้าจอจะแสดงที่อยู่ เช่น
   - `http://localhost:5173` (เครื่องนี้)
   - `same network: http://192.168.x.x:5173` (เครื่องอื่นในวง Wi-Fi/LAN เดียวกันเปิดอันนี้)
2. ถ้าเครื่องอื่นเข้าไม่ได้: Windows Firewall ต้องอนุญาต Node.js (Private network) ครั้งแรกจะมีหน้าต่างถาม → กด Allow
3. แต่ละหน้าต่างใช้ **ชื่อไม่ซ้ำกัน** ถ้าเปิด 2 แท็บในเบราว์เซอร์เดียวกัน ใช้ได้ (แต่ละแท็บจำชื่อตัวเอง)
   หรือใช้เบราว์เซอร์คนละตัว / หน้าต่าง Incognito
4. ชื่อผูกกับเบราว์เซอร์+พอร์ต: ถ้าเปลี่ยนพอร์ต ชื่อเดิมจะขึ้นว่า "belongs to another player" → ใช้ชื่อใหม่

## A. เมืองร่วม (2 หน้าต่าง: A, B)
- [ ] A และ B ล็อกอิน → New Game → ทั้งคู่อยู่ Lumina เห็นกันและกัน (ชื่อ + เลเวล + คลาส)
- [ ] A เดิน → B เห็น A เดินลื่น ไม่วาร์ป
- [ ] A ใช้วาร์ป Waystone → B เห็น A หายไปทันที (ไม่ลากเป็นเส้น)
- [ ] A ปิดแท็บ → B เห็น A หายไปภายใน ~1 วินาที
- [ ] A ไป City 2, B อยู่ Lumina → ไม่เห็นกัน

## B. ปาร์ตี้ที่ประตูดัน
- [ ] A กด E ที่ประตูดัน (Dungeon Gate) → แท็บ Party → Create Party
- [ ] B กด E ที่ประตูเดียวกัน → เห็นปาร์ตี้ของ A → Join
- [ ] กด P → เห็นสมาชิกทั้งสอง (♛ = หัวหน้า)
- [ ] A (หัวหน้า) เลือก A2 ทั้งที่ยังไม่มีใครฆ่าบอส A1 → ถูกปฏิเสธพร้อมชื่อคนที่ยังไม่ปลดล็อก
- [ ] A เลือก A1 → B ได้หน้าต่างยืนยัน → Accept → ทั้งคู่ไปโผล่ A1 ด้วยกัน
- [ ] ลองให้ B กด Decline → การเข้าถูกยกเลิก ไม่มีใครถูกย้าย

## C. ในดัน (ปาร์ตี้)
- [ ] มอนตัวเดียวกันอยู่ตำแหน่งเดียวกันทั้งสองจอ
- [ ] B ตีมอน → เลือดมอนลดทั้งสองจอ, B ได้ EXP เมื่อมอนตาย
- [ ] มอนเลือกตี B ได้ (ไม่ใช่ไล่แต่ A) → B เห็นวงเตือนสีแดงและหลบได้
- [ ] เห็นเอฟเฟกต์สกิลของเพื่อน, ร่างแยก/สัตว์อัญเชิญ/เส้นด้ายของเพื่อน
- [ ] ผู้เล่นคนที่ 3 ลงดัน A1 คนเดียว → **ไม่เห็น** ปาร์ตี้ A/B (คนละรอบ)

## D. บอส
- [ ] ฆ่า Hollow Fang (มินิบอส A1) ด้วยกัน → ทั้งคู่เห็นหลอดเลือดบอส, กลไกบอส, บอสตีทั้งสองคน
- [ ] บอสตาย → ทั้งคู่ขึ้น DEFEATED และได้รางวัล (ครั้งแรก = ไอเทมประจำบอสแน่นอน)
- [ ] log เซิร์ฟเวอร์ขึ้น `... defeated in ... — A (first), B (first)`
- [ ] เดินต่อผ่านประตูถนนของบอสได้ในรอบนี้
- [ ] กลับเมือง → ลงดันใหม่ → บอสฟื้น, ประตูถนนปิดจนกว่าจะฆ่าอีกรอบ
- [ ] ฆ่าซ้ำ → ได้ EXP + ของดรอปปกติ, ไอเทมประจำบอสลุ้นตาม %

## E. ตาย / ชุบ / กองของ
- [ ] B ล้มขณะ A ยังยืน → B นอนลง (DOWNED) ไม่ใช่ตายทันที
- [ ] A ยืนข้าง B กด E ค้าง 3 วินาที → B ลุกขึ้น
- [ ] B เก็บของในดันแล้วตายจริง (Return to Checkpoint) → ข้อความ "Lost n EXP · n item(s)" → ของหายจากกระเป๋า
- [ ] B เดินกลับจุดตาย → เห็นกองสีแดง → กด E → ของกลับมา
- [ ] (อีกรอบ) B ตาย → A เห็นกองสีฟ้า "Carry B's belongings" → กด E → ของไปถึง B แม้ B อยู่ในเมือง
- [ ] B กลับเข้าเมืองก่อนตาย → ของในรอบนั้นปลอดภัย (ตายรอบหน้าไม่เสีย)

## F. หลุด / ต่อกลับ
- [ ] ระหว่างอยู่ในดัน ปิด Wi-Fi ของ B ~5 วินาที → B เห็น "CONNECTION LOST — reconnecting…" กลางจอ
- [ ] เปิด Wi-Fi → B ต่อกลับเอง, ยังอยู่รอบเดิม, A เห็น B กลับมา, ปาร์ตี้ขึ้น online
- [ ] B หลุดนานกว่า 2 นาที → B ถูกเอาออกจากปาร์ตี้/รอบ (ต่อกลับแล้วเริ่มรอบเดี่ยวตรงที่ยืน)
- [ ] B ตายระหว่างหลุด → ยังเสียของตามปกติ (หลุดเน็ตหนีโทษไม่ได้)
- [ ] ล็อกอินชื่อ B ซ้ำจากอีกหน้าต่าง → หน้าต่างเก่ากลับหน้า Title พร้อมข้อความ "logged in from another window"
- [ ] Host (คนแรกที่เข้าแมพ) หลุด → อีกคนกลายเป็น Host, มอนยังเดินต่อ

## G. เซฟ
- [ ] เล่นแล้วรีโหลดหน้า → ล็อกอินกลับเอง → Continue → อยู่ที่เดิม ของครบ
- [ ] เปิดจากเครื่องอื่นด้วยชื่อเดิม (ต้องใช้เบราว์เซอร์เดิม เพราะ token อยู่ในเบราว์เซอร์) — ข้อจำกัดของระบบชื่อชั่วคราว

## สิ่งที่รู้อยู่แล้วว่ายังไม่ครบ (ไม่ต้องรายงาน)
- รางวัล/ไอเทมยังคิดในเครื่องผู้เล่น (Host โกงได้) → แก้ตอนทำเซิร์ฟเวอร์จำลองเกม (ดู HEADLESS_SERVER_PLAN.md)
- ระบบชื่อเป็นแบบทดสอบ (ไม่มีรหัสผ่าน)
- มอนตอนเปลี่ยน Host อาจกระโดดกลับที่เดิมเล็กน้อย
