# Eclipse Online — วิธีเล่นบนมือถือ

## 1. สิ่งที่ต้องมี
- **Android:** Chrome (เวอร์ชันล่าสุด)
- **iPhone / iPad:** Safari
- อินเทอร์เน็ตที่เสถียร (แนะนำ Wi-Fi) เกมเล่นออนไลน์เท่านั้น
- ที่อยู่เกม: `https://<ที่อยู่เซิร์ฟเวอร์>` (ขอจากผู้จัดเทส)
- **ต้องเล่นแนวนอน** ให้เปิดการหมุนจอไว้

## 2. ติดตั้งลงหน้าจอหลัก (แนะนำ: เกมจะเต็มจอ)
**Android (Chrome)**
1. เปิดที่อยู่เกม แล้วรอโหลดเสร็จ
2. กดปุ่ม **ติดตั้งแอป** ในหน้าแรก (ถ้ามี) หรือ ⋮ มุมขวาบน → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
3. เปิดเกมจากไอคอน **Eclipse** บนหน้าจอ

**iPhone / iPad (Safari)**
1. เปิดที่อยู่เกมใน **Safari** (Chrome บน iPhone ติดตั้งไม่ได้)
2. กดปุ่ม **แชร์** (สี่เหลี่ยมที่มีลูกศรชี้ขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
3. เปิดเกมจากไอคอนบนหน้าจอโฮม

> ⚠ ปิด **"ขอเว็บไซต์เดสก์ท็อป / Desktop site"** ด้วย ถ้าเปิดไว้ ปุ่มบนจออาจไม่ขึ้น (ถ้าไม่ขึ้นจริง ๆ ให้ลองแตะจอ 1 ครั้ง)

## 3. สร้างบัญชี
1. หมุนจอเป็นแนวนอน
2. พิมพ์ **ชื่อ** และ **รหัสผ่าน** อย่างน้อย 6 ตัว
3. กด **Create account** (ครั้งแรก) / **Log in** (ครั้งต่อไป)
4. เลือกคลาส แล้วกด **Begin**
5. กด **Language** เพื่อเปลี่ยนเป็นภาษาไทย

## 4. ปุ่มบนจอ
| ตรงไหน | ทำอะไร |
|---|---|
| **ครึ่งซ้ายของจอ** | แตะแล้วลากเป็นจอยสติ๊ก = เดิน |
| **ATK** (ขวาล่าง ปุ่มใหญ่) | โจมตีปกติ (แตะค้างได้) |
| **1 – 4 / ULT** (โค้งรอบ ATK) | **แตะ** = ยิงสกิลใส่เป้าหมายที่ใกล้ที่สุดให้เอง · **ลากแล้วปล่อย** = เล็งเองตามทิศที่ลาก |
| **Q** | สกิลพิเศษ (สาย Aegis = แตะค้างเพื่อกัน) |
| **DODGE** | หลบ |
| **E** | จะขึ้นเฉพาะตอนอยู่ใกล้ NPC / หีบ / ประตู / เพื่อนที่ล้ม (แตะค้างเพื่อชุบเพื่อน) |
| **≡ / กระเป๋า / ยา** (บนกลาง) | เมนู / หน้าต่างตัวละคร / ดื่มยา |

สกิลที่ยังติดคูลดาวน์จะมีเงาวนบนไอคอน ส่วนสกิลที่ยังไม่ปลดล็อกจะมืดและบอกเลเวลที่ต้องใช้

## 5. เริ่มเล่นยังไง
- **เมือง** = เขตปลอดภัย จะเห็นผู้เล่นคนอื่นที่นี่
- เดินไปที่ **ประตูดันเจี้ยน** แล้วแตะ **E** เพื่อเลือกแผนที่
  - **Solo** = เล่นคนเดียว
  - **Party** = สร้างหรือเข้าปาร์ตี้ สูงสุด 4 คน
- พื้นที่สีแดงคือสัญญาณเตือนว่าศัตรูกำลังจะโจมตีตรงนั้น ให้กด **DODGE** หลบออก
- **หลบให้ทันเวลา (Perfect Dodge)** ศัตรูจะเปิดช่องให้ตีแรงขึ้น

## 6. ⚠ กฎดันเจี้ยน (สำคัญ)
- **ตายในดันเจี้ยน:** เสีย **EXP ครึ่งหนึ่ง** ของรอบนั้น และ **ไอเทมทุกชิ้นที่ได้ในรอบนั้นจะตกเป็นกองไว้ตรงที่ตาย** (เงินไม่หาย)
  - แตะ **E** ที่กองเพื่อเก็บคืน หรือให้เพื่อนในปาร์ตี้ช่วยเก็บ
- **กลับเข้าเมือง** (ใช้หินกลับเมืองตรงจุดเริ่มแผนที่) = ของทั้งหมดจะปลอดภัย

## 7. ปัญหาที่พบบ่อย
- **ขึ้นว่า "Turn your phone sideways"** ให้หมุนเป็นแนวนอน และเช็กว่าไม่ได้ล็อกการหมุนจอไว้
- **ไม่มีปุ่มบนจอ** ให้แตะจอ 1 ครั้ง และปิด "Desktop site"
- **เน็ตหลุด / สลับไปแอปอื่น** เกมจะต่อใหม่ให้เอง ตำแหน่งในดันเจี้ยนเก็บไว้ให้ 2 นาที
- **เครื่องร้อน / กระตุก** ให้ปิดแอปอื่นที่เปิดค้าง ลดความสว่างจอ และเสียบชาร์จ
- **ตัวหนังสือเล็ก** เล่นบนแท็บเล็ตหรือคอมจะสบายตากว่า (ตอนนี้ยังเป็นเวอร์ชันทดสอบ)
