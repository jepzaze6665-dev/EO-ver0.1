# Eclipse Online — วิธีเล่นบนคอม (PC)

## 1. สิ่งที่ต้องมี
- เบราว์เซอร์ **Google Chrome** หรือ **Microsoft Edge** (Firefox เล่นได้ แต่ติดตั้งเป็นแอปไม่ได้)
- อินเทอร์เน็ต (เกมเล่นออนไลน์เท่านั้น)
- ที่อยู่เกม: `https://<ที่อยู่เซิร์ฟเวอร์>` (ขอจากผู้จัดเทส)

## 2. ติดตั้งเป็นแอป (ไม่บังคับ แต่แนะนำ)
1. เปิดที่อยู่เกมใน Chrome / Edge แล้วรอโหลดเสร็จ
2. กดปุ่ม **ติดตั้งแอป (Install App)** ในหน้าแรก แล้วกด **ติดตั้ง**
   - ถ้าไม่เห็นปุ่ม: กดไอคอน ⊕ ทางขวาของแถบที่อยู่ หรือเมนู ⋯ → แอป → ติดตั้ง Eclipse Online
3. จะมีไอคอน **Eclipse** ให้เปิดเกมบนเดสก์ท็อป / Start Menu
4. เกมอัปเดตเอง ไม่ต้องติดตั้งใหม่
5. ถ้าจะลบ ให้เปิดแอป → ⋯ มุมขวาบน → ถอนการติดตั้ง

## 3. สร้างบัญชี
1. พิมพ์ **ชื่อตัวละคร** และ **รหัสผ่าน** อย่างน้อย 6 ตัว
2. กด **Create account** (ครั้งแรก) / **Log in** (ครั้งต่อไป)
3. เลือกคลาส แล้วกด **Begin**
4. ถ้าจะเปลี่ยนเป็นภาษาไทย กดปุ่ม **Language** ในหน้าแรก หรือในเมนู Esc

> เครื่องที่เคยเข้าเล่นแล้วจะจำการเข้าระบบไว้ ครั้งต่อไปเว้นช่องรหัสผ่านว่างได้

## 4. ปุ่มควบคุม
| ปุ่ม | ทำอะไร |

| **W A S D** | เดิน |

| **1 – 4** | สกิล |
| **5** | ท่าไม้ตาย (Ultimate) |
| **Q** / คลิกขวา | สกิลพิเศษของคลาส (สาย Aegis = กดค้างเพื่อกันการโจมตี ใช้ Shift ได้ด้วย) |
| **Space** | หลบ (ใช้ Stamina) |
| **E** | คุย / เปิดหีบ / ใช้ของ / กดค้างเพื่อชุบเพื่อน |

| **Tab** | เลือกเป้าหมาย |

| **Esc** | เมนู (ตั้งค่าเสียง ภาษา แผนที่โลก ออกจากเกม) |

## 5. เริ่มเล่นยังไง
- **เมือง** (Lumina / Asteria) เป็นเขตปลอดภัย จะเห็นผู้เล่นคนอื่นที่นี่
- เดินไปที่ **ประตูดันเจี้ยน (Dungeon Gate)** แล้วกด **E** เพื่อเลือกแผนที่
  - **Solo** = เล่นคนเดียว
  - **Party** = สร้างหรือเข้าปาร์ตี้ (สูงสุด 4 คน) หัวหน้าเป็นคนเลือกแผนที่ ทุกคนต้องกดยืนยัน
- **หลบการโจมตีให้ทันเวลา (Perfect Dodge)** จะได้โบนัส และศัตรูจะเปิดช่องให้ตีแรงขึ้น
- พื้นที่สีแดงคือสัญญาณเตือนว่าศัตรูกำลังจะโจมตีตรงนั้น ให้รีบออกจากพื้นที่

## 6. ⚠ กฎดันเจี้ยน (สำคัญ)
- **ตายในดันเจี้ยน:** เสีย **EXP ครึ่งหนึ่ง** ที่ได้จากมอนสเตอร์ในรอบนั้น และ **ไอเทมทุกชิ้นที่เก็บได้ในรอบนั้นจะตกเป็นกองไว้ตรงที่ตาย** (เงินไม่หาย)
  - เดินกลับไปกด **E** ที่กองของตัวเองเพื่อเก็บคืน
  - หรือให้เพื่อนในปาร์ตี้ช่วยเก็บแทนได้
- **กลับเข้าเมือง** (ใช้ **หินกลับเมือง** ตรงจุดเริ่มแผนที่ หรือเดินกลับ) = ของทั้งหมดจะปลอดภัย และจะเห็นสรุปผลรอบที่เล่น
- บอสจะเกิดใหม่ทุกครั้งที่เริ่มรอบใหม่

## 7. ปัญหาที่พบบ่อย
- **"CONNECTION LOST — reconnecting…"** เกมจะต่อใหม่ให้เอง ตำแหน่งในดันเจี้ยนเก็บไว้ให้ 2 นาที
- **ล็อกอินอยู่ แล้วโดนเด้งกลับหน้าแรก** อาจมีคนเข้าชื่อเดียวกันจากอีกเครื่องหรืออีกแท็บ เล่นได้ทีละที่เดียว
- **ใส่รหัสผิด 5 ครั้ง** ระบบจะล็อก 60 วินาที
- **ภาพกระตุก** ให้ปิดแท็บอื่น และเปิดเกมในแท็บเดียวเท่านั้น

## 8. รายงานบั๊ก
ช่วยแจ้งผู้จัดเทสด้วย: **ทำอะไรอยู่ · แผนที่ไหน · คลาส / เลเวล · ภาพหน้าจอ**
ถ้ากด **F12 → Console** แล้วมีข้อความสีแดง ให้แคปมาด้วย ขอบคุณที่ช่วยเทสครับ!
