ECLIPSE ONLINE — UI Redesign (ทั้งเกม)

วันที่ 2026-10-01 · อ้างอิงสไตล์จากภาพตัวอย่าง (Drakantos) · ภาพในเอกสารนี้คือ ม็อกอัปที่ทำด้วยโค้ด ใช้ sprite จริงของเกมขนาด 160×160 (ตัวละครสูงประมาณ 60 px)

แนวทางสไตล์

  • มินิมอลแบบโปร่ง ใช้พื้นดำโปร่งแสง (78-92%) วางทับฉากเกมแทนกรอบหนา เส้นคั่นบาง 1 px สีครีม #ece4d2 ไฮไลต์สีทองอ่อน #e8d7a5
  • ช่องไอเทม = สี่เหลี่ยมโปร่ง ขอบเป็นสีตามความหายาก (rare ฟ้า · epic ม่วง · legendary ส้ม · mythic แดง)
  • ทุกหน้าต่างมี แถบปุ่มลัด มุมขวาล่าง เช่น EscBack TSort
  • หน้าต่างของ NPC (ร้าน / ช่างตีเหล็ก / เก็บของ) = แผงซ้ายที่ไล่สีจางไปทางขวา ฉากเกมยังมองเห็นอยู่
  • ตัวอักษรเปลี่ยนจากตัวเหลี่ยมพิกเซลเป็นตัวสะอาด (ภาษาไทยอ่านง่าย) ส่วนตัวเลขสำคัญ (POWER, เลเวล) ใช้ตัวหนา
  • กรอบพิกเซลเดิม (frame / plate / slot) ยังเก็บไว้ ใช้เฉพาะ title screen / ป๊อปอัปยืนยัน

ตัวละครในหน้าต่าง: เลือกขนาด

×1 (160 px, ตัวสูง ~60) — เล็กไป
×2 พิกเซลคม — แนะนำ

ใช้ sprite จริงแบบไม่ต้องวาดเพิ่ม ขยายเป็นจำนวนเท่าเต็ม (×2) แบบ nearest-neighbour ทำให้พิกเซลคมเหมือนในฉาก ถ้าขยายเป็นเศษส่วนภาพจะเบลอ และตัวละครยังเล่นท่าเดินหมุนให้ดูได้ด้วย

สิ่งที่ต้องการจากคุณ (รูป / ของที่ต้องหามา)

สไตล์ใหม่ส่วนใหญ่วาดด้วยโค้ดได้เลย ด้านล่างคือรายการที่ถ้ามีรูปจะสวยขึ้นมาก เรียงตามความสำคัญ (จำเป็น · ควรมี · ไม่บังคับ) ทุกไฟล์ให้วางบนพื้นดำสนิท หรือ PNG โปร่งใส สไตล์พิกเซลอาร์ตแบบเดียวกับเกม และใส่ไว้ที่ desgin/UI/v2/

#สิ่งที่ต้องการรายละเอียด / ขนาดใช้ที่ไหนระดับ
1ไอคอนแท็บกระเป๋า 6 อันทั้งหมด / Weapon Core / Armor Core / Relic / Charm / Rune (+ วัสดุ / ของใช้) เส้นขาวเดียวแบบเรียบ ขนาด 32×32 (หรือวาดใหญ่ 256 ให้ผมย่อเอง) รวมไว้ในภาพเดียว เรียงแถวเดียวแท็บกรองกระเป๋าจำเป็น
2ไอคอนเมนูบน 8 อันEquipment, Skills, Class, Codex, Quests, World Map, Settings, Save — เส้นขาวเรียบ 32×32 ภาพเดียว เรียงแถวเดียวแถบเมนูบน + แท็บจำเป็น
3ไอคอนสเตตัส ~14 อันHP, Attack, Defense, Speed, Crit, Crit Dmg, Attack Speed, CDR, Resource, Guard, Barrier, Counter, Magic, Damage Reduction — 24×24แผง Final Stats / tooltipควรมี
4กรอบเลเวลทรงเพชรสี่เหลี่ยมข้าวหลามตัด ขอบเงิน/ทอง ตรงกลางโปร่ง ~96×96 (เหมือนเลข 8 ในภาพต้นแบบ)เลเวล ในหน้าต่าง + HUDควรมี
5แท่นยืนตัวละครแผ่นพื้นสี่เหลี่ยมมองเฉียง (isometric) เส้นบาง ๆ หรือวงเวทเบา ๆ กว้าง ~320 pxใต้ตัวละครในหน้าต่าง Equipmentไม่บังคับ
6ไอคอนสกุลเงินทอง (เหรียญ/เพชร) 32×32 · ถ้ามีสกุลที่ 2 ในอนาคตก็ทำมาด้วยทุกหน้าต่างที่แสดงเงินควรมี
7ไอคอนช่องว่าง 4 อันรูปเงาจาง ๆ ของ Weapon / Armor / Relic / Charm / Rune สำหรับช่องที่ยังไม่ได้ใส่ (ในต้นแบบคือรูปหมวก แหวน สีจาง) 32×32ช่อง loadout ว่างควรมี
8ไอคอนบริการ NPCร้านค้า / ตีเหล็ก / เก็บของ / waystone / guild 32×32หัวแผง NPC + แผนที่ไม่บังคับ
9ฟอนต์ (หามา ไม่ต้องวาด)ฟอนต์ไทย+อังกฤษฟรีที่อ่านง่าย เช่น Kanit, Prompt หรือ Noto Sans Thai (Google Fonts) — บอกแค่ชื่อที่ชอบ ผมใส่ให้เองทั้งเกมเลือก 1
10ไอคอนของที่ยังไม่มีcharm_swift, charm_focus (ขนาดและสไตล์เดียวกับชุด ITEM v1.0)กระเป๋าไม่บังคับ

สิ่งที่ไม่ต้องทำ

  • รูปตัวละครตัวใหญ่ ไม่ต้องทำ ใช้ sprite เดิมขยาย ×2
  • กรอบหน้าต่าง / ปุ่ม / แถบ HP ไม่ต้องทำ สไตล์โปร่งใช้ CSS วาดได้หมด
  • ไอคอนสกิลและไอคอนไอเทมมีครบแล้ว

ขั้นตอนถัดไป

  1. คุณเลือก Layout (A / B / C หรือผสมกัน) และฟอนต์
  2. ระหว่างที่คุณทำรูป ผมทำ UI ใหม่ด้วยโค้ดไปก่อน โดยใช้ไอคอนวาดด้วยโค้ดแทนไว้ พอได้รูปมาก็เปลี่ยนเป็นรูปจริงทันที
  3. ลำดับงาน: U-A ชุดสไตล์ CSS → U-B หน้าต่างตัวละคร → U-C แผง NPC → U-D HUD + quest tracker → U-E เมนู ESC / แผนที่ / ป๊อปอัป
