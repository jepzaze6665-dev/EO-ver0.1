# A2 Ancient Valley — art prompts for the WATER LEVEL mechanic

Put the results in `desgin/Map/A/a2/WATER/` (any file name, .png).
Use the same style as the current A2 tileset (`desgin/Map/A/a2/`): top-down pixel art, 2048×2048 sheet,
plain dark navy background, tiles as separate square cards with a gap between them (do not let the cards touch).

## 1. Tileset: dry riverbed (most important)

```
Top-down 2D pixel art tileset sheet for a dark-fantasy action RPG, ancient green valley theme,
same style as a lush terraced valley with rivers and waterfalls. 2048x2048, plain dark navy background,
tiles laid out as separate square cards in a grid with clear gaps between them, no text, no labels.
Content: a DRAINED RIVERBED after the water was lowered:
- row 1: wet dark mud ground, 4 seamless variants (puddles, small pebbles)
- row 2: dry cracked silt ground, 4 seamless variants
- row 3: riverbed stones and smooth rounded rocks on mud, 4 variants
- row 4: shallow water puddle on mud (walkable), 4 variants
- row 5: river bank edge, mossy stone wall face seen from above (where the water used to be), 4 variants
- row 6: sunken ancient stone path / paving revealed under the old water, covered in algae, 4 variants
Consistent top-down lighting, muted greens, browns and teal, crisp pixel edges, no perspective, game asset sheet.
```

```

Props found on a drained riverbed:

Top-down view, muted greens, browns, teal glow accents, crisp pixel art game assets.
```
